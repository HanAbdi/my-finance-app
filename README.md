# Finance Tracker - Fullstack Personal Finance Management

Aplikasi pengelolaan keuangan pribadi berbasis web yang memungkinkan pengguna untuk mencatat transaksi, memantau anggaran bulanan, dan menganalisis pengeluaran melalui visualisasi data yang interaktif.

---

## Fitur Utama

- **Autentikasi Pengguna**: Sistem login dan registrasi yang aman menggunakan Supabase Auth.
- **Manajemen Transaksi**: Catat pemasukan dan pengeluaran dengan kategori yang dapat disesuaikan.
- **Target Anggaran (Budgeting)**: Atur batas pengeluaran bulanan dengan indikator visual _progress bar_ yang berubah warna sesuai status anggaran.
- **Visualisasi Data**: Grafik lingkaran (Pie Chart) interaktif untuk memantau alokasi pengeluaran.
- **Mode Gelap (Dark Mode)**: Antarmuka yang nyaman di mata dengan dukungan tema gelap yang elegan.
- **Pencarian & Filter**: Temukan transaksi dengan cepat menggunakan fitur pencarian dan filter berdasarkan periode bulan/tahun.
- **Ekspor Data**: Unduh laporan keuangan bulanan dalam format file CSV (Excel compatible).
- **Responsif**: Tampilan yang optimal baik di perangkat desktop maupun _mobile_.

---

## Stack Teknologi

**Frontend:**

- React.js (Vite)
- Tailwind CSS (Styling)
- Lucide React (Icons)
- Recharts (Visualisasi Data)
- Axios (API Calls)

**Backend:**

- Node.js & Express.js
- Prisma ORM (Database Management)
- PostgreSQL (Hosted on Supabase)
- Supabase (Authentication)
